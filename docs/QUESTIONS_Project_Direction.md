# QUESTIONS: Project Direction

문서 유형: 사용자 질문 기록

## 질문

```text
알고리즘 공부를 Git에 코드를 올리면서 할까?
아니면 로컬에서만 할까?
```

## 정리

```text
기록을 남기지 않을 거라면 로컬에서 하다가 필요한 것만 public으로 옮기는 방식도 충분하다.
다만 여러 컴퓨터에서 이어서 쓰고 싶다면 GitHub 저장소를 사용하는 편이 좋다.
```

## 결정

```text
GitHub에는 동기화와 백업 목적의 저장소를 둔다.
각 챕터를 Visual Studio 프로젝트 하나로 관리한다.
CMake는 사용하지 않는다.
나머지 cpp/h 파일의 내용은 직접 채운다.
```
